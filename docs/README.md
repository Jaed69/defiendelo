# Documentación de Defiéndelo

Material de apoyo del proyecto: la propuesta presentada, la investigación que la sustenta, el diseño de las pantallas y un recorrido de prueba con datos sintéticos.

| Carpeta | Contenido |
| --- | --- |
| [`propuesta/`](propuesta/) | Propuesta enviada a DSC HACK 2026 (`propuesta-dsc-hack-2026.pdf`), pitch para el jurado de 3 minutos (`defiendelo-pitch-jurado.pptx`, con guion en las notas del orador) y recorrido de la demo (`defiendelo-pitch.pptx`). |
| [`investigacion/`](investigacion/) | Informes de investigación con sus fuentes. |
| [`validacion/`](validacion/) | Conversaciones y pruebas con usuarios reales: qué asumíamos, qué aprendimos y qué cambiamos. |
| [`diseno/`](diseno/) | Archivo de diseño de los flujos (`defiendelo-flujo.pen`, se abre con [Pencil](https://pen.dev)) y capturas de las pantallas. |
| [`flujo-sintetico/`](flujo-sintetico/) | Tarea, trabajos de tres alumnos y respuestas de defensa para recorrer el flujo completo a mano, sin claves de IA. |

## Investigación

- [**Educación 2036: oportunidades**](investigacion/educacion-2036-oportunidades.md). Las cuatro grietas del reto, con evidencia peruana y tendencias hacia 2036. Defiéndelo responde a la grieta 02: la IA mejora la tarea y empeora el aprendizaje.
- [**Más valor para Defiéndelo**](investigacion/mas-valor-para-defiendelo.md). Evidencia de aprendizaje (autoexplicación, feedback), carga docente, regulación peruana de IA y caso de negocio.
- [`investigacion/notas/`](investigacion/notas/). Notas de trabajo de cada línea de investigación, con todas las fuentes citadas.

Las cifras que usamos en la aplicación y en el pitch salen de estos informes; cada una enlaza a su fuente.
